# 3MP Multimodal Diagnostic Platform: Deep Learning Pipeline

## Overview
This repository contains the source code, normalized sensor data, and processed cross-validation results for the multimodal Convolutional Neural Network (CNN) detailed in the manuscript: *[An Integrated Multimodal Magnetoelastic Microneedle Patch for Rapid Skin Cancer Screening]*.

The pipeline processes dual-channel (biomechanical and biochemical) spatial matrices generated by the transdermal 3MP sensor. It utilizes a lightweight, topologically preserved attention network optimized with Cosine Annealing to differentiate malignant tumor microenvironments from benign physiological confounders (normal tissue, scars, and inflammation).

## Repository Structure

### /Data
* **Normalized_Sensor_Tensors:** Contains representative 3x3 spatial CSV arrays for the mechanical (stiffness) and biochemical (enzymatic) readouts. These arrays have undergone global Min-Max scaling to isolate relative physical gradients prior to computational processing.
* **Publication_Results:** Contains the raw output of the 5-Fold cross-validation ablation study, including Out-Of-Fold (OOF) prediction probabilities, raw confusion matrix arrays, and extracted high-dimensional t-SNE feature coordinates for all three tested architectures (Biochemical-Only, Biomechanical-Only, and Multimodal Fusion).

### /Source_Code
* **3MP_Multimodal_Pipeline.ipynb:** The primary Jupyter Notebook. It handles the loading of the normalized 3x3 CSVs, executes native bicubic interpolation to generate high-resolution 96x96 spatial tensors, and runs the 5-Fold cross-validation ablation study using the 80-epoch Topographical Attention CNN.
* **Figure_Generator.ipynb:** A standalone script that ingests the CSVs from `/Publication_Results` to reproduce the exact ROC curves, Confusion Matrices, and t-SNE scatter plots featured in the manuscript as high-resolution vector graphics.
* **requirements.txt:** Python environment dependencies.

## System Requirements & Reproducibility
The codebase was developed and executed in a standard Python 3.10 environment utilizing a T4 GPU (Google Colab).
* TensorFlow >= 2.15.0
* Scikit-Learn >= 1.2.2
* Numpy, Pandas, Matplotlib, Seaborn
Typical installation time on a standard desktop computer is < 5 minutes.

**Note on Variance:** The 5-Fold cross-validation split is deterministically seeded (`random_state=42`) to ensure reproducible training folds. However, due to the non-deterministic nature of GPU-accelerated tensor operations in standard TensorFlow, minor fractional variances (¡À 0.5%) in final fold accuracies may occur during independent replication. The synergistic performance gap (~18%) between the single-modality baselines and the fusion model remains mathematically consistent.

## Step-by-Step Instructions for Peer Reviewers
To verify the computational methodology on a local machine, please follow these steps:
1. Ensure your environment matches the provided `requirements.txt` (Python >= 3.10).
2. Open `Source_Code/3MP_Multimodal_Pipeline.ipynb`.
3. Verify that the `dataset_dir` path in Cell 1 points to the included `/Data/Normalized_Sensor_Tensors` folder.
4. Execute Cells 1 through 3 sequentially. The script will automatically load the provided spatial matrices, apply global Min-Max normalization, execute the 5-Fold Stratified Cross-Validation, and export the Out-of-Fold probabilities.
5. Open `Source_Code/Figure_Generator.ipynb` and execute the script to instantly reproduce the exact ROC curves and Confusion Matrices presented in the manuscript.
Expected runtime on a standard GPU (e.g., NVIDIA T4) is approximately 10-15 minutes for the full 5-fold ablation study. A standard GPU (e.g., NVIDIA T4) is recommended, but standard desktop CPUs will also work at a slower speed.
